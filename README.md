# Chebarbado.github.io

Сайт-резюме на чистом HTML/CSS/JS с анимациями на [GSAP](https://gsap.com) + ScrollTrigger. Без сборки — GitHub Pages отдаёт файлы как есть.

## Как менять контент

Весь текст резюме лежит в одном файле — `js/data.js`. Пустые поля и пустые массивы на страницу не выводятся, разделы без данных скрываются вместе с пунктом меню.

## Языки

Русская версия — `js/data.js`, английская — `js/data.en.js` (переопределяет только тексты; фото, ссылки и цифры берутся из русской). Тексты интерфейса — словарь `UI` в `js/main.js`. Язык выбирается так: `?lang=en` в адресе → прошлый выбор → язык браузера. Ссылкой `…/?lang=en` можно делиться.

## Структура

- `index.html` — каркас страницы
- `css/style.css` — стили, светлая/тёмная тема, версия для печати
- `js/data.js` — контент
- `js/main.js` — рендер из `data.js` и анимации
- `img/` — фото в WebP (пути задаются в `photos` и в карточках `other` внутри `js/data.js`)
- `media/` — видео для галерей (загружается только при открытии галереи)
- `js/vendor/` — GSAP 3.15 и плагины ScrollTrigger, ScrollTo, SplitText, ScrambleText (локальные копии, без CDN)

## Анимации

Прелоадер-счётчик, имя по буквам (SplitText), «расшифровка» должности (ScrambleText), макет телефона с живым графиком телеметрии и 3D-наклоном за курсором, текст «Обо мне», наливающийся по словам при скролле, таймлайн опыта, закреплённая горизонтальная лента «Прочее» (pin + containerAnimation), круговая смена темы, курсор-кольцо и «магнитные» кнопки. Дополнительные плагины (каждый необязателен — если не загрузился, отключается только его фича): **ScrollSmoother** — инерционный скролл страницы (на тач-экранах остаётся нативный); **Flip** — навыки перелетают между группами и общим облаком; **Draggable + Inertia** — хэштеги можно хватать и бросать; **MotionPath** — планер в карточке «Штопор» и подлодка-такси в «Айсберге»; **DrawSVG** — росчерк под именем и стрелка к контактам. Плюс вариативный шрифт (буквы имени меняют вес под курсором), прилипание карточек в ленте, 3D-наклон карточек, перекос медиа от скорости скролла.

Важно: из-за ScrollSmoother контент страницы лежит внутри `#smooth-wrapper > #smooth-content`. Всё, что должно быть `position: fixed` (шапка, курсор, прелоадер, диалог), — снаружи; `position: sticky` внутри не работает, вместо него используется pin.

Раздел «Айсберг» — закреплённая сцена-погружение: ночной нью-йоркский скайлайн над водой и перевёрнутый город под ней, где каждое здание — проект (глубина ∝ объёму в ГБ), LED-строка на ватерлинии, неоновые вывески, счётчик глубины и «остановки метро» с цифрами. Все данные — в `iceberg` внутри `js/data.js`.

При `prefers-reduced-motion` всё показывается без движения (айсберг — статичной иллюстрацией со списком цифр); на узких экранах лента становится обычным столбиком, макет телефона скрыт.

